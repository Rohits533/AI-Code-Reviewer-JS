About AERO

AERO is an advanced AI-powered code debugging tool that combines Abstract Syntax Tree (AST) analysis with Google's Gemini AI to provide professional-grade code reviews.

Built by Rohit Savan, a 17-year-old AI developer from Mumbai. Deployed on Streamlit and Vercel, with the backend powered by Python and the frontend enhanced with JavaScript.
